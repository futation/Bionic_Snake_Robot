# firmware — 下位机固件

基于 Arduino 框架的 ESP32-S3 蛇形机器人主控程序（工程名 `Snack_Move`，八节蛇）。

## 功能概览

- **正弦运动算法**：可调摆幅、波速的蛇形步态生成
- **自校准算法**：上电自动扫描并校准舵机中位
- **手动校准**：配合上位机逐个舵机微调
- **动作组模式**：自定义动作序列（"编舞"）
- **BLE 蓝牙**：与上位机无线通信（二进制 + 字符串双协议）
- **RGB 状态灯**：上电白灯、蓝牙连接绿灯、掉电红灯

## 编译与烧录

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)（需 1.6.10 以上，支持子目录源码递归编译；1.8.x / 2.x 均可），在开发板管理器中安装 **ESP32** 板支持包
2. 库管理器中安装 **Adafruit NeoPixel**
3. 打开 `Snack_Move/Snack_Move.ino`，选择对应开发板与端口，编译上传

硬件引脚：舵机总线 UART1（RX=7, TX=8），NeoPixel GPIO21。

## 目录结构

代码按分层架构组织，与[《代码框架说明》](../docs/代码框架说明/README.md)中的分层一一对应：

```
Snack_Move/
├── Snack_Move.ino        # 入口：setup/loop 调度
└── src/
    ├── servo/            # 舵机总线协议与驱动：帧结构/指令码/校验和、运动指令、ID管理、EEPROM存储、舵机对象池
    ├── motion/           # 运动算法与校准：正弦步态、全自动校准、手动校准、槽位扫描
    ├── comm/             # 通信协议：字符串命令、二进制协议、BLE蓝牙
    ├── app/              # 应用层：模式管理、动作组
    └── hal/              # 板载外设：NeoPixel 状态灯
```

> 💡 **一句话理解代码分工：** 协议层负责"怎么传数据"，驱动层负责"怎么转舵机"，运动层负责"怎么扭成蛇形"，校准层负责"怎么让舵机听话"。

## 适配硬件

- 自研舵机驱动板 **Bus-Driver-Neo**（硬件文件见 [hardware/](../hardware/README.md)）
- 幻尔（Hiwonder）总线舵机系列
- 12V 锂电池供电（电流容量 ≥ 2800mA）
