## 二进制协议总设计

| 包头   | 命令字 | 长度  | 数据...   | 校验和   | 包尾   |
| :----- | :----- | :---- | :-------- | :------- | :----- |
| `0xAA` | `Cmd`  | `Len` | `Payload` | **`CS`** | `0x55` |

* **校验和计算规则：**
  * **计算范围**：`Cmd` + `Len` + `Payload` 的所有字节。
  * **计算公式**：`CS = 0xFF - (Cmd + Len + Payload[0] + ... + Payload[N]) & 0xFF`
    (注：若累加和变量为 8 位类型，则 `& 0xFF`可省略，手动计算验证的时候也可以不管）
* `Len` 字段表示 **Payload** 部分的长度。
  * 例如单舵机指令长度为 5，动作组（3个舵机）长度为 15。

***

## 校准界面协议

### 1. `0x05` — 进入手动校准模式

- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：  `AA 05 00 FA 55`
- **绑定界面操作**：  
  点击 **“手动校准模式开关”**（打开）时发送。成功收到下位机 `0x04` 反馈后，开关保持打开，并自动触发后续参数加载。

---

### 2. `0x06` — 下位机上报所有舵机参数

- **方向**：下位机 → 上位机  
- **Payload**：每个舵机 4 字节：`[ID, Pos_L, Pos_H, Offset]`（`Offset` 为有符号数，范围 -125~125，传输时加 256 转为 0~255）  
- **示例**（上报 2 个舵机：ID=1，Pos=500，Offset=0；ID=2，Pos=600，Offset=-20）  
  - ID1: Pos=500 → 低 0xF4，高 0x01；Offset=0 → 0x00  
  - ID2: Pos=600 → 低 0x58，高 0x02；Offset=-20 → 236 (0xEC)  
  - Payload 字节序列：`[0x01, 0xF4, 0x01, 0x00, 0x02, 0x58, 0x02, 0xEC]`，Len=8  
  - 校验和：`Cmd=0x06`，Len=8，Payload 和 = 0x01+0xF4+0x01+0x00+0x02+0x58+0x02+0xEC = 0x1F4？取低 8 位 0xF4；`CS = 0xFF - (0x06+0x08+0xF4) = 0xFF - 0x102 = 0xFD`（取低 8 位）  
  - 完整包：`AA 06 08 [Payload] FD 55`
- **绑定界面操作**：  
  在 **进入校准模式（`0x05`）成功后**，下位机自动返回此包。上位机解析后**动态生成舵机卡片列表**（每个卡片显示对应 ID 的 Position 和 AngleOffset）。

---

### 3. `0x01` — 实时调整单舵机（不保存）

- **方向**：上位机 → 下位机  
- **Payload**：`[ID, Pos_L, Pos_H, Offset]`（`Offset` 有符号 -125~125，传输时加 256 转为 0~255）  
- **示例**：调整 ID=1 的舵机到 Position=500，Offset=+10  
  - Pos=500 → 低 0xF4，高 0x01  
  - Offset=+10 → 0x0A  
  - Payload：`[0x01, 0xF4, 0x01, 0x0A]`，Len=4  
  - 校验和：`Cmd+Len+Payload和 = 0x01+0x04+ (0x01+0xF4+0x01+0x0A)=0x01+0x04+0x100=0x105`，低 8 位 0x05，`CS=0xFF-0x05=0xFA`  
  - 完整包：`AA 01 04 01 F4 01 0A FA 55`
- **绑定界面操作**：  
  用户**拖动某舵机卡片的“位置脉冲”滑动条/输入框**，或 **“角度偏差”滑动条/输入框** 时，立即发送此指令，下位机让对应舵机做出实时动作（不写入 EEPROM）。

---

### 4. `0x03` — 保存当前调整结果到舵机 EEPROM

- **方向**：上位机 → 下位机  
- **Payload**：`[ID, Pos_L, Pos_H, Offset]`（同上）  
- **示例**：保存 ID=1 的当前界面参数（Position=520，Offset=-5）  
  - Pos=520 → 低 0x08，高 0x02  
  - Offset=-5 → 251 (0xFB)  
  - Payload：`[0x01, 0x08, 0x02, 0xFB]`，Len=4  
  - 校验和：`0x01+0x04+0x01+0x08+0x02+0xFB = 0x107`，低 8 位 0x07，`CS=0xFF-0x07=0xF8`  
  - 完整包：`AA 03 04 01 08 02 FB F8 55`
- **绑定界面操作**：  
  点击某舵机卡片上的 **“实时保存”按钮** 时发送。下位机收到后将 Position 写入该舵机的 EEPROM，并调用 `LobotSerialServoSaveOffset` 保存 AngleOffset。成功后返回 `0x04` 反馈。

---

### 5. `0x08` — 读取当前所有舵机参数（主动查询）

- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：`AA 08 00 F7 55`（`CS=0xFF-0x08=0xF7`）  
- **绑定界面操作**：  
  点击界面上的 **“读取参数”按钮** 时发送。下位机收到后（不移动舵机）立即重新读取每个舵机 EEPROM 中的 Position 和 AngleOffset，打包成 `0x06` 格式返回给上位机，用于**刷新当前界面显示的参数**。

---

### 6. `0x07` — 修改舵机 ID

- **方向**：上位机 → 下位机  
- **Payload**：`[oldID, newID]`（各 1 字节）  
- **示例**：将旧 ID=2 改为新 ID=5  
  - Payload：`[0x02, 0x05]`，Len=2  
  - 校验和：`0x07+0x02+0x02+0x05 = 0x10`，低 8 位 0x10，`CS=0xFF-0x10=0xEF`  
  - 完整包：`AA 07 02 02 05 EF 55`
- **绑定界面操作**：  
  点击 **“舵机ID调试”按钮**，在弹出的对话框中选择旧 ID、输入新 ID 并确认后发送。下位机修改总线中对应舵机的 ID，成功后返回 `0x04` 反馈。上位机随后应重新进入校准模式或刷新列表。

---

### 7. `0x04` — 通用操作成功反馈

- **方向**：下位机 → 上位机  

- **Payload**：`[状态码]`  
  
  | Payload[0] | 含义                           | 触发命令 |
  | :--------- | :----------------------------- | :------- |
  | `0x01`     | 参数读取成功                   | `0x08`   |
  | `0x02`     | 参数保存成功                   | `0x03`   |
  | `0x03`     | ID 修改成功                    | `0x07`   |
  | `0x10`     | 进入手动校准模式成功           | `0x05`   |
  | `0x11`     | 退出手动校准模式成功           | `0x09`   |
  | `0x12`     | 进入动作组模式成功             | `0x0A`   |
  | `0x13`     | 退出动作组模式成功             | `0x0B`   |
  | `0x14`     | 舵机掉电成功                   | `0x0E`   |
  | `0xFF`     | 通用失败（可选第二个字节原因） | 任何命令 |
  
  原因码可定义为：
  
  | 原因码 | 含义                | 适用场景                                       |
  | :----- | :------------------ | :--------------------------------------------- |
  | `0x01` | 校验和/格式错误     | 数据包校验失败、包尾错误、Len 字段异常         |
  | `0x02` | 参数无效            | ID 超范围、Position/Offset/Time 非法           |
  | `0x03` | 执行超时/舵机无响应 | 舵机通信超时、EEPROM 写入失败、ID 修改后无响应 |
  | `0x04` | 模式不匹配          | 在当前模式下不允许执行该命令                   |
  | `0x05` | 硬件状态不允许      | 舵机掉电状态下收到运动指令                     |
  | `0x06` | 舵机数量为零        | 总线上无舵机，无法完成操作                     |
  
  **反馈包示例**：
  `AA 04 02 FF 03 CS 55` 表示“通用失败，原因为执行超时/舵机无响应”。
  
- **示例**：保存成功反馈 → `AA 04 01 02 F8 55`（`Cmd+Len+Payload = 0x04+0x01+0x02=0x07`，`CS=0xFF-0x07=0xF8`）  

- **绑定界面操作**：  
  上位机在发送 `0x05`、`0x03`、`0x07`、`0x09`（退出）等命令后，**等待此反馈**。收到后更新界面状态（例如显示“保存成功”，或允许开关最终保持打开/关闭）。

---

### 8. `0x09` — 退出手动校准模式

- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：`AA 09 00 F6 55`（`CS=0xFF-0x09=0xF6`）  
- **绑定界面操作**：  
  当用户**关闭“手动校准模式开关”** 时发送。下位机收到后退出特殊校准状态，不再响应 `0x01` 实时调整（或恢复正常运动模式）。成功后返回 `0x04` 反馈，上位机**清空所有舵机卡片**。

---

### 汇总表（指令与界面操作绑定）

| 命令字 | 方向      | 触发界面操作                | 说明                                            |
| ------ | --------- | --------------------------- | ----------------------------------------------- |
| `0x05` | 上位→下位 | 打开手动校准模式开关        | 进入模式，归位500脉冲，期待 `0x06` 返回参数列表 |
| `0x06` | 下位→上位 | （自动接收）                | 上报舵机列表，用于生成卡片                      |
| `0x01` | 上位→下位 | 拖动位置/偏差滑动条或输入框 | 实时调整舵机（不保存）                          |
| `0x03` | 上位→下位 | 点击某卡片的“实时保存”按钮  | 保存当前参数到 EEPROM                           |
| `0x08` | 上位→下位 | 点击“读取参数”按钮          | 重新查询并刷新所有舵机参数                      |
| `0x07` | 上位→下位 | 确认 ID 调试对话框          | 修改指定舵机 ID                                 |
| `0x04` | 下位→上位 | （自动接收）                | 反馈上一条指令执行结果，用于界面提示            |
| `0x09` | 上位→下位 | 关闭手动校准模式开关        | 退出校准模式，清空界面列表                      |

以上协议完整覆盖了角度校准界面的所有交互需求。实际开发时，请按照此规范进行下位机固件与上位机蓝牙通信的编码。

## 动作界面协议

### 1. `0x0A` — 进入动作组模式
- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：  
  `AA 0A 00 F5 55`  
  （校验和：`0xFF - (0x0A + 0x00) = 0xF5`）  
- **绑定界面操作**：  
  用户打开“动作组模式开关”时发送。下位机收到后：  
  - 停止当前所有运动，复位状态标志。  
  - 忽略除动作组相关指令（`0x02`、`0x0A`~`0x0F`）以外的其他命令。  
  - 返回 `0x04` 成功反馈（状态码 `0x01`）。上位机收到反馈后开关保持打开。

---

### 2. `0x0B` — 退出动作组模式

- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：  
  `AA 0B 00 F4 55`  
  （`CS = 0xFF - 0x0B = 0xF4`）  
- **绑定界面操作**：  
  用户关闭“动作组模式开关”时发送。下位机恢复默认指令处理（可接收校准指令等）。返回 `0x04`（`0x01`）成功后，上位机关闭开关并清空动作组编辑界面。

---

### 3. `0x0E` — 舵机掉电
- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：  
  `AA 0E 00 F1 55`  
  （`CS = 0xFF - 0x0E = 0xF1`）  
- **绑定界面操作**：  
  在动作组模式下，点击“舵机掉电”按钮。下位机立即切断所有舵机动力（PWM 输出禁止或发送掉电指令），此时用户可手动掰动蛇形机器人关节到任意姿态。下位机需返回反馈对应的掉电成功反馈指令。

---

### 4. `0x0C` — 扫描舵机位置（上电并读取）
- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：  
  `AA 0C 00 F3 55`  
  （`CS = 0xFF - 0x0C = 0xF3`）  
- **绑定界面操作**：  
  用户手动调整舵机到目标姿态后，点击“扫描并读取位置”按钮。下位机执行：  
  1. 给所有舵机上电（若之前掉电）。  
  2. 等待稳定（如 200ms）。  
  3. 逐一读取每个舵机的**实时位置脉冲**（0~1000）。  
  4. 将结果打包成 `0x0D` 格式返回给上位机。  

---

### 5. `0x0D` — 上报扫描结果（舵机ID + 当前位置）

- **方向**：下位机 → 上位机  
- **Payload**：每个舵机占 **3 字节**：`[ID, Pos_L, Pos_H]`，数量可变（N 个舵机，Len = 3×N）  
- **示例**：假设两个舵机 ID=1 位置 500，ID=2 位置 723  
  - ID1: Pos=500 → 低 0xF4，高 0x01  
  - ID2: Pos=723 → 低 0xD3，高 0x02  
  - Payload：`[0x01, 0xF4, 0x01, 0x02, 0xD3, 0x02]`，Len=6  
  - 校验和：`Cmd(0x0D) + Len(0x06) + Payload和 = 0x0D+0x06+ (0x01+0xF4+0x01+0x02+0xD3+0x02) = 0x13+0x1D7=0x1EA`，低 8 位 0xEA，`CS=0xFF-0xEA=0x15`  
  - 完整包：`AA 0D 06 01 F4 01 02 D3 02 15 55`  
- **绑定界面操作**：  
  上位机收到此包后，解析出每个舵机的 ID 和当前脉冲，并显示在“动作组示教面板”中（例如表格或舵机卡片列表）。用户可基于这些数值保存为一个静态动作组（随后用 `0x02` 发送）。
- **注意：**如果总线上没有舵机，`0x0D` 的 Payload 长度应为 0。应明确定义：`AA 0D 00 CS 55`。

---

### 6.`0x02` — 执行静态动作组

- **场景**：  

  - 舵机 ID=1，运动到位置 300（0x012C），运行时间 500ms（0x01F4）  
  - 舵机 ID=2，运动到位置 400（0x0190），运行时间 500ms（0x01F4）

- **Payload 构造**（共 2 × 5 = 10 字节）：

  ```C
  [0x01, 0x2C, 0x01, 0xF4, 0x01,  0x02, 0x90, 0x01, 0xF4, 0x01]
   ID1  PosL PosH TimeL TimeH   ID2  PosL PosH TimeL TimeH
  ```

- **完整数据包**（十六进制）：`AA 02 0A 01 2C 01 F4 01 02 90 01 F4 01 48 55`

  - `0xAA`：包头  
  - `0x02`：命令字（动作组）  
  - `0x0A`：Len = 10（Payload 字节数）  
  - `01 2C 01 F4 01 02 90 01 F4 01`：Payload  
  - `0x48`：校验和（计算过程：`Cmd+Len=0x02+0x0A=0x0C`；Payload 和 = 0x01+0x2C+0x01+0xF4+0x01+0x02+0x90+0x01+0xF4+0x01 = 0x1AB → 低8位 0xAB；`CS = 0xFF - (0x0C+0xAB) & 0xFF = 0xFF - 0xB7 = 0x48`）  
  - `0x55`：包尾

- **绑定界面操作**：  
  在动作组模式下，用户点击 **“发送动作组”** 按钮（例如从示教生成的姿态，或 JSON 咒语解析出的单步动作），上位机即发送上述指令。下位机收到后**驱动所有舵机以指定速度/时间**运动到目标位置。

  > **注意**：若需要连续多个动作组（例如咒语序列），上位机应在每个 `0x02` 指令之间加入 **延时**（delay），延时时间应 ≥ 当前动作组的运行时间（Time 字段值），避免指令覆盖导致运动被打断。下位机不自行延时。

---

### 四、指令汇总表（动作组模式相关）

| 命令字 | 方向      | 触发界面操作       | Payload 格式                             | 说明                                       |
| ------ | --------- | ------------------ | ---------------------------------------- | ------------------------------------------ |
| `0x0A` | 上位→下位 | 打开动作组模式开关 | 无                                       | 进入模式，复位下位机状态，忽略非动作组指令 |
| `0x0B` | 上位→下位 | 关闭动作组模式开关 | 无                                       | 退出模式，恢复全指令响应                   |
| `0x0E` | 上位→下位 | 点击“舵机掉电”     | 无                                       | 切断所有舵机动力，允许手动掰动             |
| `0x0C` | 上位→下位 | 点击“扫描位置”     | 无                                       | 上电并读取所有舵机实时位置，返回 `0x0D`    |
| `0x0D` | 下位→上位 | （自动接收）       | `[ID, Pos_L, Pos_H]` × N                 | 上报扫描到的舵机 ID 和当前脉冲位置         |
| `0x02` | 上位→下位 | 发送静态动作组     | `[ID, Pos_L, Pos_H, Time_L, Time_H]` × N | 执行一个姿态（所有舵机同时运动）           |
| `0x04` | 下位→上位 | （自动接收）       | `[状态码]`                               | 进入/退出模式成功反馈（状态码 `0x01`）     |

## 运动参数查询协议

### 1. `0x0F` — 查询运动极限参数

- **方向**：上位机 → 下位机  
- **Payload**：无（Len=0）  
- **示例**：`AA 0F 00 F0 55`（`CS = 0xFF - 0x0F = 0xF0`）  
- **绑定界面操作**：  
  上位机需要获取当前蛇形机器人的运动极限参数时发送。此命令可在**任意模式**下使用（不受校准/动作组模式限制）。下位机收到后立即返回 `0x10` 上报包。

---

### 2. `0x10` — 上报运动极限参数

- **方向**：下位机 → 上位机  

- **Payload**：22 字节，按 IEEE 754 单精度浮点（小端序）+ uint16 依次排列：  

  | 偏移 | 长度 | 类型   | 含义                                     |
  | :--- | :--- | :----- | :--------------------------------------- |
  | 0    | 4    | float  | **A_max**：最大允许振幅（度）            |
  | 4    | 4    | float  | **V_max**：最大波传播速度（关节间隔/秒） |
  | 8    | 4    | float  | **λ_min**：推荐波长下限（关节间隔数）    |
  | 12   | 4    | float  | **λ_max**：推荐波长上限（关节间隔数）    |
  | 16   | 4    | float  | **λ_current**：当前设定的默认波长值        |
  | 20   | 2    | uint16 | **sineMoveTime**：当前正弦步态单步时间（ms） |

- **示例**：假设 A_max=60.0°, V_max=15.5, λ_min=2.0, λ_max=6.0, λ_current=6.0, sineTime=500  

  - Payload 字节序列（IEEE 754 小端序 + uint16 小端）：  
    `[0x00,0x00,0x70,0x42,  0x00,0x00,0x78,0x41,  0x00,0x00,0x00,0x40,  0x00,0x00,0xC0,0x40,  0x00,0x00,0xC0,0x40,  0xF4,0x01]`，Len=22  
  - 完整包：`AA 10 16 [22字节Payload] CS 55`

- **绑定界面操作**：  
  上位机收到此包后，解析出各项极限参数和当前设定值，用于界面展示（如滑块范围限制、参数合法性校验、当前值回显等）。

---

### 汇总表（运动参数查询）

| 命令字 | 方向      | 触发界面操作           | Payload 格式                                                                | 说明                             |
