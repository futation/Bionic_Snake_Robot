# docs — 设计文档

## 文档目录

### [运动算法](运动算法/算法提炼.md)
蛇运动算法的推导设计，是本项目理论性最强的部分，也是做科研的切入点。配套讲解视频：*《蛇运动算法》*。

### [字符串通信协议](字符串通信协议/字符串通信协议文档.md)
上位机第二个界面（运动控制）所使用的命令协议，也是其他遥控端直接发送的命令，用于控制蛇的运动（初级控制）。

### [二进制通信协议](二进制通信协议/通信协议.md)
上位机与下位机之间的二进制通信协议（主要用于第三、第四个界面）。为什么同一套系统要设计两套协议？见 [《为什么要设计该协议》](二进制通信协议/为什么要设计该协议.md)。

### [上位机 json 命令](上位机json命令/动作序列json.md)
上位机第四个界面动作组 json 命令的设计，用于蛇自定义任意步态，俗称"编舞"。

**0 代码编舞**：把 [动作序列json.md](上位机json命令/动作序列json.md) 和 [提示词.txt](上位机json命令/提示词.txt) 直接发给 AI，对应输入动作 1、2、3……即可生成动作序列 json，导入上位机即可执行。
